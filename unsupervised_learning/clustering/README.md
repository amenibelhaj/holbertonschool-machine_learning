# Clustering

K-means, Gaussian Mixture Models with the EM algorithm, and hierarchical clustering, implemented with numpy, scikit-learn and scipy.

## Files

- 0-initialize.py: Initialize K-means
- 1-kmeans.py: K-means
- 2-variance.py: Variance
- 3-optimum.py: Optimize k
- 4-initialize.py: Initialize GMM
