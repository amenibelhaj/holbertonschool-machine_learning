# GANs

Generative adversarial networks: simple GAN, Wasserstein GAN with weight clipping and with gradient penalty, and convolutional networks for face generation, implemented with Keras.

## Files

- 0-simple_gan.py: Simple GAN
- 1-wgan_clip.py: Wasserstein GAN with weight clipping
- 2-wgan_gp.py: Wasserstein GAN with gradient penalty
- 3-generate_faces.py: Convolutional generator and discriminator
